# MotoLogger Workspace Rules (GEMINI.md)

This repository is governed by the unified agent and coding guidelines defined in [`AGENTS.md`](./AGENTS.md).

### Quick Summary of Mandatory Rules:
1. **Chat Language:** Always communicate with the user in **Czech** (Čeština).
2. **Code & Comments:** All code, comments, variables, documentation, and git commits must strictly be in **English**.
3. **Design System:** Pure **Apple Design System** (Cupertino light theme, `#F2F2F7` / `#FFFFFF`, `#1C1C1E`). No tacky dark neon glow, no robotic "AI look" or generic AI phrases.
4. **Ergonomics:** Large touch targets, consistent button heights (`54 px`), screen auto-locks during riding, no technical jargon in rider-facing UI.
5. **Quality Gate:** Zero errors on `flutter analyze`, all unit tests passing in `flutter test`, clean PlatformIO firmware compilation.
6. **Architecture & Hardware Reference:** Consult [`PROJECT.md`](./PROJECT.md) for full hardware, firmware, and app specifications.
